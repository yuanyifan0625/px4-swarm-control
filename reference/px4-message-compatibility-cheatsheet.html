PX4 Message Compatibility

遇到欄位不存在或 topic 接不到時，依序檢查 shape、name、endpoint；不要先改上層。

目前固定 contract

項目固定值
PX4 firmwarev1.17.0 @ d6f12ad
px4_msgsv1.17.0 @ 86d8239
VehicleStatusv1；沒有 accepts_offboard_setpoints
Translation node不需要

三步診斷

  1. Shape：ros2 interface show 確認實際欄位與 MESSAGE_VERSION。
  2. Name：v0 無 suffix；v1 使用 _v1。
  3. Endpoint：ros2 topic info -v 必須看到真正 publisher；topic list 不夠。

安全 fallback

bool(getattr(status, "accepts_offboard_setpoints", False))

缺欄位代表「PX4 沒有明確提供資訊」，不是可以從 nav_state 猜出答案。

Topic 規則

version = int(getattr(message_type, "MESSAGE_VERSION", 0))
suffix = "" if version == 0 else f"_v{version}"
